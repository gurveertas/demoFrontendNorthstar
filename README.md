# Northstar

A responsive business-development dashboard demo built with React, Vite, and Tailwind CSS.

## Get started

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

The demo includes an opportunity pipeline with search and filters, an add-opportunity form, performance metrics, and an interactive daily focus list. All data is local to the current browser session.
